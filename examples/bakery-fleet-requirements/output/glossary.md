# Glossary — OvenLink

| Term | Definition |
|------|------------|
| Northbake | Northbake — manufacturer of bakery equipment (ovens, provers, dough handling) |
| RC&S | Remote Control and Statistics — this product |
| NB-touch panel | Touch panel installed on Northbake ovens (standard on A/B/C series since 2013-11-02); replaces button panel |
| Oven series | C, I, S, V — Northbake oven series types; panel features vary by series |
| Panel roles | User, Baker, Service, Supervisor (Northbake-only) — roles on the NB-touch panel, selected via pin code |
| Remote Control (legacy) | Existing 1:1 panel feature: mirror panel UI on PC via IP, download/upload recipes, upload logos |
| Fleet | The set of ovens owned by one client (observed range: 1–300 ovens across stores) |
| VW-600 | Oven controller board by Voltware AB (fictional supplier); Linux 2.6.30; UI on Nano-X |
| Voltware AB (fictional supplier) | Supplier of the panel hardware+software platform; releases 2×/year; source access restricted |
